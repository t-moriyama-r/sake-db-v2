# マイページ編集ページ仕様

## アクセス制御

- 認証: **必須**（実質的にログイン必須）
- ページレベルのガードなし。`MyPageEditForm` コンポーネント側で処理

## 表示内容

- プロフィール編集フォーム（名前・自己紹介・アイコン画像）
  - アイコン画像は `ImageUpload` コンポーネントで選択し、base64エンコードして Cognito カスタム属性 `custom:imageBase64` に保存する

## パスワード変更

- 新しいパスワードを入力した場合、現在のパスワードの入力も必須
- 現在のパスワードが未入力のままパスワード変更を試みると `schemas/auth.ts` の `userEditSchema` でバリデーションエラーになる
- パスワードを変更しない場合（新しいパスワード欄が空）は現在のパスワードの入力不要

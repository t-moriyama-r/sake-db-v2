# マイページ仕様

## アクセス制御

- 認証: **必須**
- 未ログイン時: `getServerUserProfile()` でプロフィール取得に失敗した場合、サーバーサイドで `/login` へリダイレクト

## 表示内容

- ユーザーのプロフィール情報（アバター・名前・メール・自己紹介）
- ブックマークしたお酒一覧（`BookMark` モデルから取得）
- プロフィール編集ボタン → `/mypage/edit` へ遷移

## エラーハンドリング

- ブックマーク取得は `fetchBookmarksSSR()` がサーバーサイドで行う
- 取得失敗時の専用エラー表示は現時点では実装されていない

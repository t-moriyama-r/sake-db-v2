# マイページ仕様

## アクセス制御

- 認証: **必須**
- 未ログイン時: ログイン画面（`/login`）へクライアントサイドリダイレクト
- ガード方式: `MyPageView` コンポーネント内で `useAuth()` の `isLogin` を監視してリダイレクト

## 表示内容

- ユーザーのプロフィール情報（アバター・名前・メール・自己紹介）
- ブックマークしたお酒一覧（`BookMark` モデルから取得）
- プロフィール編集ボタン → `/mypage/edit` へ遷移

## エラーハンドリング

- ブックマーク取得（`BookMark.list` / `Liquor.get`）が失敗した場合、`console.error` でログを出力し、`useToast` によるエラートーストをユーザーに表示する
- エラー発生時もページはクラッシュせず、ブックマーク一覧は空のまま表示される

# 酒詳細ページ仕様

## アクセス制御

- 認証: **不要**（未ログインでも閲覧可）
- 存在しない ID: `notFound()` → 404

## UI要素ごとの表示条件

| UI要素 | 未ログイン | ログイン済み |
|---|---|---|
| タグ追加ボタン | **表示・操作可**（仕様） | 表示・操作可 |
| タグ削除ボタン | **表示・操作可**（仕様） | 表示・操作可 |
| 編集ボタン（ペンアイコン） | **表示**（仕様） | 表示 |
| 削除ボタン（ゴミ箱アイコン） | **非表示** | 表示 |
| 投稿するボタン | **表示・投稿可**（仕様） | 表示・投稿可 |

## 非自明な挙動の詳細

### タグ追加・削除（未ログインでも操作可）

`authMode: 'identityPool'` を使用しており、Cognito Identity Pool のゲストアクセスで誰でも操作できる。
これは意図した仕様であり、バグではない。

### 編集ボタン（未ログインでも表示）

ボタン押下で `/liquor/edit/[id]` へ遷移する。アクセス制御は遷移先ページには存在しないため、
誰でも編集画面に遷移・編集操作が可能。これは意図した仕様。

### 投稿する（未ログインでも可）

`authMode = user ? 'userPool' : 'apiKey'` で切り替え。未ログイン時はゲスト名を入力して投稿できる。

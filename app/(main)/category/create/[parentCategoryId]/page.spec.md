# カテゴリ作成ページ仕様

## アクセス制御

- 認証: **必須**
- 未ログイン時: `/` へサーバーサイドリダイレクト（`getServerUser()` による）
- admin 限定ではない。ログインユーザーなら誰でもカテゴリを作成できる

## `parentCategoryId === 'root'` の特殊ケース

URL パラメータ `parentCategoryId` に `'root'` が渡される場合（`/category/create/root`）は、管理画面などから「親カテゴリ未指定のまま」カテゴリ作成画面へ遷移してきたことを示すプレースホルダーである。

- `'root'` は「ルートカテゴリの直下に作成する」という意味ではない
- **ルートカテゴリ（最上位カテゴリ）は SE 作業で DB に直接挿入するハードデータであり、ユーザーがカテゴリを作成する際は必ず親カテゴリを指定しなければならない**
- 親カテゴリが未選択のままサブミットするとバリデーションエラー（「親カテゴリを選択してください」）になる。これは `parentCategoryId` の値によらず常に適用される。
- 作成成功後のリダイレクト先は、選択した親カテゴリの詳細ページ（`/category/{parentId}`）
